# Senior Saathi

A multilingual digital-learning companion that helps senior citizens use smartphones, the internet, digital payments, and online services safely.

## Features

- Lessons and quizzes in English, Hindi, Marathi, Gujarati, Tamil, and Telugu
- Learning progress tracking
- Profile with required name and age, plus an optional photo or senior avatar
- Course-completion certificate with a unique ID
- Supabase-backed profile and learning data
